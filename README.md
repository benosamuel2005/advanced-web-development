
# Advanced Web Development – Course Management System

A web-based Course and Trainer Management System developed using Java, Spring Boot, Thymeleaf, and PostgreSQL as part of the BSc (Honours) Computing programme at Dublin Business School.

## Features
- Create and manage courses
- View all available courses
- Edit course information and capacity
- Delete existing courses
- Assign trainers to courses
- View trainer information
- Form validation
- Responsive user interface

## Technologies Used
- Java
- Spring Boot
- Spring MVC
- Spring Data JPA
- Thymeleaf
- PostgreSQL
- HTML5 and CSS3
- Maven
- Git and GitHub

## Project Structure
- `course/` – Course entities, controllers, services and repositories
- `trainer/` – Trainer entities, controllers, services and repositories
- `templates/` – Thymeleaf HTML pages
- `static/css/` – Shared stylesheet

## Key Learning Outcomes
- Developed a layered Spring Boot application
- Implemented CRUD operations
- Integrated PostgreSQL with Spring Data JPA
- Created dynamic web pages using Thymeleaf
- Applied reusable frontend components
- Used Git for version control

## Running the Application
1. Clone the repository.
2. Configure your PostgreSQL database in `application.properties`.
3. Run the Spring Boot application.
4. Open `http://localhost:8080/course-management`.
